BioScan AI — Asisten Interaktif Pembelajaran Biologi
=========================================================

Isi:
- index.html  : struktur aplikasi
- style.css   : tampilan/responsive UI
- script.js   : navigasi, BioScanner simulasi, chatbot, kuis, dashboard, galeri

Cara menjalankan:
1. Simpan ketiga file dalam satu folder.
2. Buka index.html di Chrome/Edge/Firefox.
3. Tidak membutuhkan server untuk demo dasar.

Catatan penting:
- LK-3 menyebut Streamlit/Python, Teachable Machine/OpenCV, Gemini API, GitHub dan Streamlit Cloud.
- Versi HTML/CSS/JavaScript ini adalah "hasil karya yang dapat ditampilkan" sebagai prototype front-end mandiri yang merepresentasikan komponen LK-3.
- BioScanner dan Tanya BioAI pada versi ini berjalan sebagai simulasi lokal; integrasi model AI/API sungguhan memerlukan backend/API key dan tidak ditanamkan ke browser agar kredensial aman.
- Kuis demo menampilkan 5 soal inti; rancangan LK-3 menyebut modul 10 soal HOTS.
